# Population structure in GWAS and SNP heritability: a simulation on 1000 Genomes chromosome 22

Phenotypes are simulated with known causal variants on real genotypes (2,504 people, 26 populations), so an
unadjusted association scan, a PC-adjusted scan and a GRM-based REML heritability estimate can each be scored
against the truth. PLINK 2 does QC, PCA and scans; R does simulation, scoring and REML; bash and Slurm scripts run it.

**Report:** [`report/report.pdf`](report/report.pdf) (source: `report/report.qmd`).
Per-replicate results: [`results/tables/summary.csv`](results/tables/summary.csv).

## Result in brief (10 replicates x 2 scenarios, 30 causal variants, h2 about 0.4)
- Unadjusted scans are heavily inflated: median genomic inflation 9.8 (no population shift) and 40.5 (with one); 10 PCs bring it to about 1.2.
- Unadjusted scans flag on average 17 and 24 megabase windows far from any causal variant; adjusted scans flag 0 and 0.1.
- The adjusted scan recovers about 10 to 12 of 30 causal variants; the report does not attribute that loss to the correction alone.
- REML SNP heritability: mean bias -0.03 (no shift) and +0.07 / +0.04 (shift, without / with PCs).
- One chromosome, simple architecture, 10 replicates: these numbers describe this design only.

## Does LD score regression separate confounding from polygenicity?
Genomic inflation cannot tell the two apart, so the simulation is used to test a method that claims it can
(`scripts/04_ldsc.sh`). Scenario A has no environmental confounder by construction; scenario B has one.
- **The intercept carries information lambda does not.** Scenario A's unadjusted scans have a median lambda of 9.8
  but a median LD-score intercept of **1.05**; scenario B's rise to **1.81**. Within scenario A the intercept is
  *negatively* correlated with lambda (-0.66), so it is not just re-reading the inflation.
- **It is not reliable per replicate.** In A the intercept spans 0.57 to 1.99 and 3 of 10 replicates call confounding
  that does not exist; in B, 3 of 10 miss a confounder that does.
- **After PC adjustment it is biased upward** (1.14 in both scenarios, above 1 in 6/10 and 7/10 replicates) including
  in A, where nothing is left to find.
- **The slope is unusable here**: implied h2 of 1.7 and 5.3 against a truth near 0.4. Thirty large effects on one
  chromosome are not the polygenic architecture LDSC assumes, and the LD scores come from the same 26-population
  sample rather than a matched reference panel.

## Run
```bash
micromamba create -y -f environment.yml      # plink2, bcftools
bash src/00_download.sh                      # 1000 Genomes chr22 (about 200 MB, public)
bash run_local.sh                            # QC, 20 replicates, aggregate (about 30 min on a laptop)
bash scripts/04_ldsc.sh                      # LD score regression (about 45 min, mostly LD scores)
quarto render report/report.qmd              # R: data.table, ggplot2, knitr, jsonlite
# On a Slurm cluster:  bash slurm/submit_all.sh
```
The intermediate data (`results/qc`, `results/tasks`) are not in this repository; they are regenerated by the commands above.

## What was and was not tested
| Item | Status |
|---|---|
| QC, 20 replicates, scoring, report | Run end to end on macOS (Apple silicon), system bash 3.2, PLINK 2.0, R 4.5 |
| `scripts/env.sh` under bash and zsh 5.9 | Run (`tests/test_shells.sh`) |
| LD score regression (`scripts/04_ldsc.sh`) | Run end to end on macOS. LD scores for all 97,216 variants take about 45 min |
| Slurm scripts | Syntax-checked only. Never submitted to a scheduler; resource requests are estimates |
| Linux and Windows | Smoke tests only: the bash/zsh environment test, shell syntax checks and the REML self-test passed on Ubuntu, macOS and Windows in GitHub Actions (28 Oct 2026). The full pipeline was not run there, and `run_local.ps1` has not been run |
